# ZOLI — Manifesto de Recuperação

Este arquivo define o que deve ser recuperado do ambiente local e colocado no GitHub.

## Legado

- [ ] Código-fonte original do ZOLI EVENTOS
- [ ] `main.js`
- [ ] `preload.js`
- [ ] `renderer/`
- [ ] `package.json`
- [ ] configurações de build
- [ ] scripts auxiliares
- [ ] assets próprios
- [ ] documentação existente

## ZOLI 2.0

- [ ] frontend Next.js
- [ ] backend
- [ ] schema Prisma
- [ ] migrations
- [ ] configurações PostgreSQL sem credenciais
- [ ] testes
- [ ] documentação
- [ ] scripts de desenvolvimento
- [ ] scripts de produção

## Segurança

Antes de qualquer upload:

- [ ] remover `.env` com segredos
- [ ] remover tokens
- [ ] remover chaves privadas
- [ ] remover credenciais de banco
- [ ] remover dados pessoais de usuários
- [ ] revisar arquivos grandes e binários

## Regra

Somente arquivos efetivamente recuperados devem ser marcados como concluídos.
